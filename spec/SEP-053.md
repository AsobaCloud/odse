# SEP-053: Deterministic Physical Residuals & Level 2 Non-Deep Anomaly Detectors

**Status:** Implemented  
**Issue:** [#69](https://github.com/AsobaCloud/odse/issues/69)  
**Packages:** `odse.physics`, `odse.detectors`, re-export via `odse.adapters.pvlib`

## 1. Overview

SEP-053 adds zero-GPU, pure NumPy/Pandas physical residuals and Level 2 heuristic detectors to ODS-E. Obvious binary dropouts and thermal stacking are handled in open source; multi-step latent world models remain commercial.

## 2. Physics residuals (`odse.physics`)

Formulas do **not** import the `pvlib` package. The SEP SDK import path re-exports from the adapter:

```python
from odse.adapters.pvlib import inject_physical_residuals
# equivalent:
from odse.physics import inject_physical_residuals
```

### 2.1 Faiman cell temperature

$$T_{\text{cell}} = T_{\text{amb}} + \frac{G}{u_0 + u_1 \cdot v_{\text{wind}}}$$

Defaults: $u_0 = 25.0$, $u_1 = 6.84$ (open-rack crystalline silicon / IEC 61853).

### 2.2 Expected AC power

Temperature-derated DC estimate times a European-weighted inverter efficiency curve peaking at $98.6\%$ at high load. Output is clipped to $[0, P_{\text{rated}}]$ and forced to $0$ when $G < 5\,\text{W/m}^2$.

### 2.3 Residual columns

| Column | Definition |
|---|---|
| `t_cell_expected` | Faiman $T_{\text{cell}}$ |
| `p_expected` | Expected AC power (kW) |
| `delta_p_norm` | $(P_{\text{ac}} - P_{\text{expected}}) / P_{\text{rated}}$ |
| `delta_t_divergence` | $T_{\text{inv}} - T_{\text{cell, expected}}$ (only if device `temperature` present) |

### 2.4 Column contract

`inject_physical_residuals` resolves (first match wins):

| Role | Candidates |
|---|---|
| Power | `kW`, `active_power_kW`, `p_mp`, `power_kw`, `power` |
| Irradiance | `poa_irradiance`, `poa_global`, `irradiance`, `ghi` |
| Ambient | `ambient_temperature_c`, `temp_air`, `ambient_temp_c` (**required**; no silent night-proxy) |
| Wind | `wind_speed_ms`, `wind_speed` (default $1.0\,\text{m/s}$ if absent) |
| Inverter temp | `temperature`, `temperature_c`, `temp_inv` |

Requires `pip install 'odse[dataframe]'` (pandas).

## 3. Level 2 detectors (`odse.detectors`)

Interface: `fit` / `score` / `detect` on `BaseDetector`.

| Detector | Rule | Default |
|---|---|---|
| `BinaryDropoutDetector` | $G > g_{\min}$ and $\Delta P_{\text{norm}} < -\tau$ (one-sided) | $\tau=0.50$, $g_{\min}=200$ |
| `ThermalDivergenceDetector` | $\Delta T_{\text{div}} > \tau$ sustained $\ge N$ steps per asset | $\tau=15^\circ\text{C}$, $N=3$ |
| `RollingCUSUMDetector` | IEC 61724-style PR CUSUM $S_t > h$ | $k=0.5$, $h=4.0$, $g_{\min}=100$ |
| `PhysicalHeuristicDetector` | Concatenates the three detectors’ event frames | — |

Anomaly event columns:

`timestamp`, `asset_id`, `detector_type`, `severity`, `residual_value`, `rule_triggered`

Detectors expect pre-enriched residuals (CLI and `PhysicalHeuristicDetector(rated_capacity_kw=...)` call inject when needed).

## 4. CLI

```bash
odse detect \
  --input site_telemetry.csv.gz \
  --rated-kw 330 \
  --weather durban_weather_6mo.csv.gz \
  --out-anomalies alerts.json
```

Optional `--weather` performs a backward `merge_asof` of hourly `temp` onto telemetry as `ambient_temperature_c`.

## 5. Open-source vs commercial boundary

| Layer | Location | Scope |
|---|---|---|
| Level 2 residuals & heuristics | `AsobaCloud/odse` (this SEP) | Binary dropouts, thermal divergence, PR CUSUM |
| Multi-step latent world models | Commercial `anomalyModelService` | Precursor trajectory forecasting, latent drift |
