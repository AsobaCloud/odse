# SEP-049: Electrical & Per-Phase Measurement Fields for `energy-timeseries`

**Status:** Draft · **Issue:** #56 · **Change class:** Normative, additive

## Motivation

Three-way drift between the schema file, transformer emissions, and the pvlib adapter vocabulary (see issue #56 for `file:line` evidence). The schema declares `additionalProperties: false` while transformers emit `kW`, `voltage_ac`, `current_ac`, `frequency`, `voltage_dc`, `current_dc`, `temperature`, and more — none defined. Per-phase voltage/current is not representable at all, blocking distribution-grid unbalance analysis.

## Canonical Vocabulary & Naming Rule

The schema adopts the **emitted** vocabulary (transformers are the de facto contract; CHANGELOG 0.6.0 documented it). The pvlib adapter's private vocabulary is realigned separately (SEP-050), since its keys were never schema-legal.

**Naming rule:** unit-suffixed lowercase (`ambient_temperature_c`, `poa_irradiance`, `wind_speed_ms`). `kW`/`kVA`/`kVArh`/`PF` are grandfathered historical canonicals and must not be extended.

## Fields Added (all optional → non-breaking)

| Field | Type | Unit | Notes |
|---|---|---|---|
| `kW`, `kVAr` | number | kW, kVAr | interval active/reactive power |
| `voltage_ac`, `voltage_ac_l1/l2/l3` | number ≥ 0 | V | bare form = aggregate (mean) |
| `current_ac`, `current_ac_l1/l2/l3` | number ≥ 0 | A | bare form = aggregate (sum) |
| `frequency` | number ≥ 0 | Hz | |
| `voltage_dc`, `current_dc` | number ≥ 0 | V, A | string/circuit level |
| `temperature`, `ambient_temperature_c`, `module_temperature_c` | number | °C | |
| `poa_irradiance`, `ghi`, `dni`, `dhi` | number ≥ 0 | W/m² | |

## Enforcement

1. `tests/test_schema_conformance.py` — strict Draft 2020-12 validation of transformer fixture output (known-exceptions list targeted at zero; currently zero), plus `SCHEMA_FIELDS` parity check pinning `validator.py` to the schema file.
2. `validate()` emits non-fatal `UNKNOWN_FIELD` warnings for out-of-schema keys.

## Compatibility

Purely additive optional properties; no field redefined; `additionalProperties: false` retained.
