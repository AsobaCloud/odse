# Roadmap

All roadmap planning, prioritization, and status tracking lives in **[ODSE Roadmap — GitHub Project #7](https://github.com/orgs/AsobaCloud/projects/7)**.

Issues follow the **SEP (Schema Enhancement Proposal)** format with priority labels (`P0`, `P1`, `P2`) and milestone groupings. See any `[SEP-XXX]` issue in the project board for the canonical specification, acceptance criteria, and implementation status.
